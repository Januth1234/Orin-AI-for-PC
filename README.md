# Orin AI

Orin AI is a free, AI-native desktop code editor built around an agent that can understand, change, and explain your code as it works.

## What it does

- **Chat** for questions, planning, and codebase exploration.
- **Agent** for tools and live code edits, with streamed changes and checkpoints.
- Bring your own model provider, API key, local Ollama models, or custom MCP servers.
- A focused desktop workspace with an animated bolt that shows when Orin is working.

## Development

```sh
npm install
npm run buildreact
npm run compile
```

For a Windows desktop build, run `npm run gulp vscode-win32-x64` after dependencies are installed.
